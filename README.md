# Diary Agent 日記正向輔導器

### 核心思想
- 日記除了記錄自己的心情以外，可以拿來做分析
- 提供正向思考指導，讓你變得更正向不厭世

### 評核標準
- 天氣: (待使用)預計讓使用者勾選是否加入天氣加權
